## Authoring (Document Authoring)

Model: `standalone`

## Supported variations

| Variation | Option class |
| --- | --- |
| Dark band (light cards on dark section) | `dark` |
| Inverse (dark cards, light text) | `inverse` |
| Taupe (warm neutral cards) | `taupe` |
| Plain (white cards) | `plain` |
| Gap top (extra space above the band) | `gap-top` |
